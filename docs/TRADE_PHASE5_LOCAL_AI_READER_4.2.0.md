# Trade Phase 5 — Real Local AI Reader

สถานะซอร์ส: พัฒนาบนฐาน 4.2.0 ก่อนออกรุ่นใหม่

## สิ่งที่ทำจริง

- เพิ่ม `AI_READER_INPUT_V1` ซึ่งรับเฉพาะ MarketPacket ที่ยืนยันแล้วและแท่งปิดไม่เกิน 40 แท่ง
- ส่งข้อมูลไปยัง Ollama ผ่าน `127.0.0.1:11434` ใน Electron main process เท่านั้น ไม่ใช้ API key และไม่ส่งไป Cloud
- ตรวจรูปแบบผลลัพธ์และปฏิเสธฟิลด์ออเดอร์, lot, leverage, entry, SL หรือ TP
- รายงานของโมเดลมีสถานะ `SHADOW_READER` และถูกตรึง `decisionEligible=false`, `executionInfluence=false`, `weightInfluence=false`
- ถ้า Ollama/โมเดลไม่มีอยู่จริง ระบบรายงานว่าไม่พร้อมและไม่สร้างคำตอบจำลองแทน
- ผลลัพธ์ที่บันทึกไว้ถูกตรวจสัญญาใหม่ทุกครั้งเมื่อเปิดโปรแกรม

## สถานะเครื่องตรวจสอบ

วันที่ 22 สิงหาคม 2026 ตรวจไม่พบ `ollama.exe` จึงยังไม่มีผลอ่านจากโมเดลจริงบนเครื่องนี้ การเชื่อมต่อพร้อมใช้หลังติดตั้ง Ollama และโมเดล Local อย่างน้อยหนึ่งตัว

## การทดสอบสำคัญ

- รับเฉพาะสัญญาข้อมูลแท่งปิดที่ยืนยันและจำกัดขนาด
- ยอมรับรายงานจากผู้ให้บริการ Local ที่ระบุชัดเจนเท่านั้น
- ปฏิเสธคำตอบที่แอบใส่คำสั่ง BUY/SELL หรือข้อมูลออเดอร์
- ปฏิเสธสถานะบันทึกที่ปลอมอำนาจการส่งคำสั่ง
